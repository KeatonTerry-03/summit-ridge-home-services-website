# Summit Ridge Home Services Website

Static multi-page website prototype based on the Summit Ridge Home Services Figma Make design and client brief.

See [`WORKLOG.md`](WORKLOG.md) for the source review, implementation decisions, uncertainties, and verification record.

## Preview locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Pages

- Home (`index.html`)
- Services (`services.html`)
- About (`about.html`)
- Contact (`contact.html`)

## Notes

- The estimate form is intentionally a demonstration only and does not transmit data.
- The text logo should be replaced when `summit-ridge-logo.png` is supplied.
- Photography uses external Unsplash placeholder URLs and should be replaced with approved client photography before production launch.
